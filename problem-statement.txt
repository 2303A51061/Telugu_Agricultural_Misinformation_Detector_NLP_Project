**NLP-Based Detection of Agricultural Misinformation in Telugu Social Media – Fake-News Detection** is a Natural Language Processing and Machine Learning project developed to detect potentially false, misleading, exaggerated, or unsupported agricultural information written in Telugu and shared through social-media-style content. Agriculture-related information about seeds, fertilizers, pesticides, crop diseases, irrigation, soil, weather, crop yield, organic farming, government schemes, market prices, farming techniques, pest control, and agricultural machinery can influence farmers' decisions, while unreliable information can lead to incorrect agricultural practices. The main objective of this project is to create a structured Telugu agricultural dataset containing INFORMATION and MISINFORMATION samples, clean and validate the dataset using Python, apply Telugu NLP preprocessing techniques, extract useful text features using methods such as TF-IDF, and develop machine learning models such as Logistic Regression, Naive Bayes, Support Vector Machine, and Random Forest for classification. The project will also investigate suitable Telugu-supporting or multilingual transformer models such as IndicBERT, MuRIL, mBERT, or XLM-R, depending on available computational resources. The performance of the developed models will be evaluated using Accuracy, Precision, Recall, F1-Score, Confusion Matrix, and other suitable evaluation measures, followed by error analysis to understand common misclassification cases. The project also aims to develop a simple application where a user can enter Telugu agricultural text and receive a predicted classification as INFORMATION or MISINFORMATION. The research will investigate whether NLP techniques can effectively detect agricultural misinformation in Telugu, how different preprocessing and feature-extraction techniques affect classification, how traditional machine learning models compare with transformer-based approaches, and what challenges are involved in Telugu agricultural misinformation detection. The overall project roadmap includes project definition, dataset creation and annotation, dataset cleaning and validation, exploratory data analysis, Telugu NLP preprocessing, feature extraction, machine learning model development, model evaluation, transformer-based modeling, error analysis, final model preparation, prediction-system development, web-application development, testing, research-paper preparation, project-report preparation, PPT and demonstration, and final project submission. The final system is intended as a research prototype for identifying potentially misleading agricultural content and is not intended to replace professional agricultural experts or independent fact-checking.
